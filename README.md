# scrap-wings-site

The public site for **Scrap Wings** — a landing page and the privacy policy that the
Google Play listing links to.

Two static files, no build step, served by GitHub Pages from the repository root.

- `index.html` — landing page
- `privacy.html` — privacy policy (the URL given to Play Console)

The game itself is developed separately. Contact: matanestudiosgames@gmail.com
